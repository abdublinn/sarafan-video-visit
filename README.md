# Видео визита к клиенту

Операционный пайплайн подготовки видео-кейса формата «Руководство приезжает в гости к клиенту через несколько месяцев после монтажа».

Часть курса **«Сарафанные продажи в мебели на заказ: Стратегия, Психология, Система»** (Дублин А.Б., 2025–2026).

## Сайт

Опубликован на GitHub Pages:
**https://abdublinn.github.io/sarafan-video-visit/**

## Что внутри

Девять документов, описывающих полный цикл подготовки одного ролика — от выбора кейса до съёмки:

|---|---|---|
| 00 | Процесс подготовки видео-визита | Главный дирижёр пайплайна |

## Принципы формата (короткое напоминание)

- **Клиент — герой, мы — проводник** (StoryBrand).
- **Стори, а не отзыв** (T.R.U.S.T. → Real experience + Transparency).
- **Один кадр закрывает один психотип** (Бергер × Хизы → Экспертиза / Статус / Забота).

Главный антипринцип: никаких корпоративных интервью. Если в подготовке начинает преобладать «расскажите как вам с нами работалось» — стоп, пересобираем.

## Как устроен репозиторий

```
.
├── *.md                       # исходные документы в Obsidian Flavored Markdown
├── docs/                      # сгенерированные документы для сайта (kebab-case URL)
├── mkdocs.yml                 # конфигурация сайта (MkDocs Material)
├── requirements.txt           # Python-зависимости (mkdocs-material, mkdocs-callouts)
├── scripts/
│   └── sync.py                # синхронизация *.md → docs/ с конвертацией wikilinks
└── .github/workflows/
    └── deploy.yml             # автодеплой на GitHub Pages при push в main
```

Исходные `.md` в корне — рабочие документы в Obsidian, с wikilinks `[[Name]]` и callouts `> [!info]`. Скрипт `scripts/sync.py` транслитерирует имена в kebab-case и переписывает wikilinks в обычные ссылки; callouts конвертируются плагином `mkdocs-callouts` в `admonition`-блоки автоматически.

## Локальная разработка

```bash
pip install -r requirements.txt
python scripts/sync.py
mkdocs serve
```

Сайт откроется на http://127.0.0.1:8000/

## Деплой

При каждом push в `main` запускается [GitHub Action](.github/workflows/deploy.yml), который:
1. Запускает `scripts/sync.py` — обновляет `docs/` из исходных `.md`.
2. Запускает `mkdocs gh-deploy` — собирает сайт и публикует на ветку `gh-pages`.

GitHub Pages автоматически отдаёт содержимое `gh-pages` по адресу сайта.
